红磡 → 东铁线大埔墟站 → 28K专线小巴或72／72A／73A／74A九巴至「松仔园」站 → 朝大埔方向步行约50米至避车处入口，再沿马路上行约2分钟到起点。

回程 约1–1.25小时

松仔园 → 同一批巴士或28K回大埔墟站 → 东铁线红磡。班次以九巴及专线小巴最新公布为准。

选线前知道

四条林径都从同一个起点出发、绕一圈回到原点，可以按体力和时间任选一条；想加量也可以在岔口转走另一条。护理区以保护生态为主，不设烧烤炉并严禁生火，康乐设施比郊野公园少。

临行复查

必须在「松仔园」站下车，不是「大埔滘公园」站。啡径、黄径要过溪流与泥泞段，大雨或雨后数天内不宜，此时改走红径或自然教育径。夏季入夜后林道有萤火虫，夜间行走请自备照明并避免强光长时间照射。

怎么走山顶广场／凌霄阁 → 卢吉道 → 卢吉道观景台 → 夏力道 → 回凌霄阁（全程环回，不必原路折返）

去程 约1–1.25小时

红磡 → 港铁至中环（约25分钟）→ 中环交易广场乘15号巴士、香港站乘1号专线小巴，或花园道乘山顶缆车至山顶（约35–45分钟）→ 沿山顶道步行至卢吉道起点。三者的班次与票价以运营商最新公布为准。

回程 约1–1.25小时

山顶 → 15号巴士／1号小巴／山顶缆车回中环 → 港铁回红磡。看夜景后下山人流集中，候车时间会比白天长。

选线前知道

山顶环回步行径由卢吉道与夏力道组成，全长约3.5公里，地势平缓、以水泥路为主，是本清单里最轻松的一段。想加长，可改走港岛径第1段（山顶 → 薄扶林水塘，7公里，约2.25小时）单程下山，不走回头路。

临行复查

卢吉道临崖路段有风化与陡峭地貌，务必按路标行走，不要跨越围栏。周末及公众假期山顶缆车、15号巴士和1号小巴排队较长，建议预留候车时间，或改乘巴士／小巴。
