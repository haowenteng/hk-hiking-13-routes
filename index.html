西贡 · 山海穿越

东坝 → 西湾亭

水库、白沙湾与开阔山海

中等偏强

水库蓝与浪茄白沙相接，上山后视野打开；一条线同时看沙滩、海湾和山脊。

主线距离约8公里（估）
纯步行3–4小时
红磡往返整天9–11小时
现场预留4.5–5.5小时

怎么走万宜水库东坝 → 浪茄湾 → 西湾山 → 吹筒坳 → 西湾亭

去程 约2–2.5小时

周末／公众假期：红磡 → 钻石山 → 96R至北潭涌 → 9A至东坝。平日可经西贡转的士，不能照搬这套接驳。

回程 约1.5–2.5小时

西湾亭 → NR29至西贡 → 92至钻石山 → 红磡。先查NR29返程班次，再确定下山时间。

选线前知道

浪茄之后持续爬坡，曝晒明显。这是缩短穿越线，不是完整麦径第二段；不含破边洲支线，也不下西湾海滩。
